# 📖 Voca

轻量桌面单词学习工具，支持全局划词翻译、OCR 截图识别、闪卡复习与生词本管理。

## 功能

- **全局划词翻译** — 选中文字后按住 Ctrl 快速双击 C，悬浮翻译窗口即时弹出
- **OCR 截图翻译** — Ctrl+Shift+O 框选屏幕任意区域，自动识别文字并翻译
- **一键收藏与复习** — 悬浮窗可单独点击 ⭐ 收藏，也可点击 ⚡ 加入闪卡池；后者会同时保存到当前收藏目标生词本，支持单词、短语和句子，并保留已有复习进度
- **闪卡复习** — 使用 FSRS-6 安排间隔，到期词优先、每日新词限额和短时重学，支持独立的提前练习
- **多生词本** — 按主题分类管理，支持导入/导出，内置 CEFR / CET / IELTS / TOEFL / GRE / SAT 预设词表
- **学习统计** — 打卡连续天数、掌握程度分布、每日目标进度
- **全局搜索** — 跨所有生词本搜索单词或翻译
- **Anki 导出** — 导出为 TSV 格式，可直接导入 Anki
- **多翻译引擎** — 支持 Google 翻译、DeepL、MyMemory

## 闪卡复习

先回忆词义，再翻面核对。翻面前会隐藏中文释义、英文定义、例句和同义词。用数字键 1–4 评分：**没想起来 / 费力想起 / 正常想起 / 轻松想起**。“费力想起”表示独立答对；没想出来应选第一档。

短语和句子自动使用整行宽度，学习记录默认折叠，可用右上角按钮展开。长文本按长度调整字号、保留换行，并在卡片内滚动；评分按钮保持可见，长段落翻面后直接定位到译文。

默认目标保持率为 90%，每日最多引入 10 个新词，重学间隔为 10 分钟，每轮开始 20 张卡片；均可在「设置 → 闪卡复习」调整。打开闪卡后会直接开始背诵，无需再次设置或点击开始。目标保持率是模型的调度目标，越高通常需要越频繁地复习，并非保证实际记忆率。使用锁定版本的 `ts-fsrs@5.2.3`（FSRS-6），目前使用库的默认模型参数。

正式队列优先安排已到期的学习/重学卡和复习卡，再加入限额内的新词。每轮数量限制的是初始卡片数，忘记的词可能再次出现。等待重学时可以离开，下一次到期后继续；没有到期卡片时不会自动提前抽卡。“提前练习”保存独立作答记录，不改变正式间隔、每日新词额度或正式复习统计。

每次正式评分会一起保存卡片状态、逐次日志和作答统计，中途退出不会丢失已完成的作答。学习记录显示最近五次作答。完整日志保存在词库 JSON 的 `reviewLogs` 中，含评分、时间、实际间隔及调度前后的状态，供后续分析或训练个人参数；历史总次数无法还原为逐次记录，因此不会补造历史日志。

已有卡片保留原到期时间，在下一次正式复习时切换。旧卡初始记忆状态由历史间隔估计，迁移当次日志会标记 `legacyEstimate`；未复习的卡不会被批量改期。“学习阶段”替代原先的“掌握系数”，不再将间隔倍率显示成掌握百分比。

## 开发

```bash
# 安装依赖
npm install

# 启动开发模式
npm run dev

# 打包
npm run dist

# 更新版本并发布打包到 release/
npm run release -- 1.0.9
```

**技术栈：** Electron · Vue 3 · Vite
